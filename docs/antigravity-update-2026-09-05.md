# Проверка обновлений Antigravity — 5 сентября 2026

Сравнены ClaudeGravity `6e6a4f5` и [confeden/Antigravity `71d053d`](https://github.com/confeden/Antigravity/commit/71d053d) (последнее изменение 2 сентября 2026, версия пакета 2.11.0).

Это разные приложения: Antigravity Unlocker патчит установленные программы Google и настраивает ОС, ClaudeGravity отправляет Cloud Code API-запросы через Node.js gateway. Изменения Rust-программы нельзя применить к нему через merge. Сетевая поддержка реализована в ClaudeGravity самостоятельно средствами Node.js и существующего Undici; код, бинарники и закрытые ключи Unlocker в runtime не включаются.

| Изменения Antigravity | Решение для ClaudeGravity |
|---|---|
| Прежний DNS-провайдер перестал подменять Cloud Code; появился DoH-провайдер | Добавлен dns.dns-ai.ru через встроенный HTTP/2, прежние UDP-серверы оставлены резервом, добавлены две резервные группы |
| Маршрутизация только двух региональных Cloud Code-хостов | Удалены generativelanguage.googleapis.com и antigravity-unleash.goog из selective Smart DNS |
| Свой прокси имеет приоритет | HTTPS_PROXY/HTTP_PROXY и NO_PROXY обрабатывает EnvHttpProxyAgent, только для Cloud Code; заданный dispatcher сохраняется |
| DNS и соединения не должны надолго зависать | Ограничения на DoH, UDP и установление соединения; объединение параллельных DNS-запросов и кэш с TTL |
| Реакция на региональный 400 и неисправные маршруты | Следующий маршрут только после отказа до соединения или явного регионального 400; минутная пауза для неудачного маршрута отдельно по каждому хосту |
| Исправления таймаутов pooled TLS-туннелей | Ограничивается только установка соединения; общий таймер не уничтожает активные потоки модели |
| Переключение маршрутов по замерам скорости; закрытые relay/exits | Закрытых маршрутов в ClaudeGravity нет. Используется порядок DoH → UDP-группы → системный DNS, с переключением по фактической ошибке; фонового ранжирования по скорости нет |
| Определение VPN и привязка DNS к интерфейсу провайдера | Системная конфигурация и маршруты интерфейсов не меняются; свой прокси имеет приоритет, системный DNS остаётся резервом |
| NRPT, HTTPS_PROXY на уровне ОС, откат CA, Windows-служба, watchdog, glibc Linux | Не применимо: ClaudeGravity не устанавливает DNS-службы/CA, не патчит IDE/CLI и уже работает на Windows/macOS/Linux |
| Удаление Gemini CLI из меню | Не применимо к CG-Agent: он использует локальный Cloud Code endpoint, а не Gemini CLI |

Обновление с DNS-патча v1 выполняется при применении compatibility patch, повторный запуск не изменяет уже обновлённые файлы. Неизвестный формат старого патча завершает обработку ошибкой до записи файлов.

Проверки без Google-аккаунта:

```bash
node tests/smart-dns.mjs
node tests/proxy-compat.mjs
bash tests/unix-installer.sh
node distribution/build-runtime.mjs
node tests/distribution.mjs dist/ClaudeGravity
```

Проверки маршрутизации включены и в Windows CI. Реальное получение ответа модели требует Google OAuth и доступной квоты; DNS/TLS-проверка без учётных данных этого не доказывает.
